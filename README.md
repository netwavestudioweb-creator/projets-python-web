## 🔒 Bonne pratique appliquée partout

Aucun secret (clé API, token, mot de passe) n'est codé en dur : tout passe par des **variables d'environnement**. Les mots de passe ne sont jamais stockés en clair.

## 🚀 Utilisation

Chaque projet s'ouvre indépendamment : un `index.html` dans un navigateur pour les projets web, ou `python <fichier>.py` pour les projets Python (voir le `README.md` de chaque dossier).
