# 🍲 Au Goût Béninois

Site de **partage de recettes béninoises** : parcourir par catégorie, rechercher, consulter une fiche détaillée et soumettre ses propres recettes.

> Projet web d'**Adriano DODO**.

## ✨ Fonctionnalités

- 🔎 **Recherche** instantanée par nom ou description
- 🏷️ **Filtres** par catégorie (Entrées, Plats principaux, Desserts)
- 📖 **Fiche détaillée** (ingrédients + étapes) en fenêtre modale
- ➕ **Soumettre une recette** : enregistrée localement (`localStorage`) et ajoutée aussitôt
- 📰 Newsletter et design **responsive** (mobile / bureau)
- 6 recettes béninoises fournies (Amiwo, Atassi, Wagasi, Ata, Dégué, Klui-klui)

## 🚀 Utilisation

Aucune installation : **ouvrez `index.html`** dans un navigateur (double-clic). Tout fonctionne hors-ligne.

## 🔧 Ce qui a été refait

L'ancienne version était une page statique **cassée** : liens vers des pages `.php` inexistantes, image de fond mal placée, et un `fetch()` vers une API fictive qui échouait toujours. Le site est désormais une **application monopage fonctionnelle**, sans backend ni dépendance.
